# skills-playground

A collection of Claude Code skills.

## Skills

### `react-vite-stack`

Bootstraps a production-ready React frontend with:

- Vite + TypeScript
- TanStack Router (file-based routing)
- TanStack Query + DevTools
- Mantine UI (dark/light mode toggle, system preference default)
- Vitest + Testing Library
- ESLint + Prettier

**Usage:** Say "scaffold a new frontend app called `<name>`" and Claude will set up the full stack for you.
